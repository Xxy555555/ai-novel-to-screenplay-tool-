# 前端原型设计文档 ——「ScriptForge」AI 小说转剧本工具

> 版本：v1.0 ｜ 日期：2026-06-05 ｜ 用途：用于 Open Design 搭建可交互原型
> 配套文档：`docs/PRD.md`（产品需求）、`docs/yaml-schema-design.md`（数据结构）
> 视觉基调：**深色影视工作台**（深色底 + 高级灰 + 琥珀/金强调色）

---

## 0. 如何使用本文档（给原型设计）

本文档不写代码，提供搭建原型所需的一切：**设计令牌（颜色/字体/间距）→ 页面地图 → 逐屏线框图 → 组件清单 → 交互与状态**。建议在 Open Design 中：
1. 先按「第 2 节 设计令牌」建立颜色/文字/间距样式库（Styles / Variables）。
2. 按「第 5 节 组件清单」建可复用组件（Components）。
3. 按「第 6 节 逐屏原型」逐页拼装，线框图里的 `①②③` 对应该屏下方的「组件标注」。
4. 按「第 7 节 交互与状态」连接原型跳转与状态切换（Prototype 连线）。

## 1. 设计目标与原则

| 原则 | 说明 |
|------|------|
| **专业片场感** | 深色工作台 + 琥珀强调，像剪辑/剧本软件，建立"专业工具"信任感 |
| **过程可见** | AI 不是黑盒：章节切分、角色识别、场景生成逐步可见（呼应 SSE 亮点） |
| **结构即编辑** | 左中右三栏，结构化数据可视化、可直接改，卡片与 YAML 双向同步 |
| **可信可溯源** | 每个场景能回看原文片段；质量分量化改编质量 |
| **零门槛演示** | 无 Key 也能跑（stub），首页一键示例，3 步看到成片 |

## 2. 设计令牌（Design Tokens）

### 2.1 颜色

**底色 / 表面（由深到浅）**
| Token | 色值 | 用途 |
|-------|------|------|
| `bg/base` | `#0E1116` | 全局背景（近黑炭灰） |
| `bg/surface` | `#161B22` | 面板/卡片底 |
| `bg/raised` | `#1C232D` | 悬浮卡片/输入框/下拉 |
| `bg/inset` | `#0A0D12` | 代码/YAML 编辑区底 |
| `border/default` | `#2A3441` | 分割线/描边 |
| `border/strong` | `#3A4654` | 高亮描边/选中边 |

**文字**
| Token | 色值 | 用途 |
|-------|------|------|
| `text/primary` | `#E6EDF3` | 主文字 |
| `text/secondary` | `#9DA7B3` | 次要文字/说明 |
| `text/muted` | `#6E7681` | 占位/弱提示 |

**强调与语义**
| Token | 色值 | 用途 |
|-------|------|------|
| `accent/primary` | `#E8B349` | 主强调（琥珀金）：主按钮、进度、品牌 |
| `accent/hover` | `#F2C45E` | 强调悬停 |
| `accent/soft` | `rgba(232,179,73,0.14)` | 强调浅底（选中行/标签底） |
| `success` | `#3FB950` | 通过/合法 |
| `warning` | `#D29922` | 警告/需人工补 |
| `danger` | `#F85149` | 错误/校验失败 |
| `info` | `#58A6FF` | 信息/链接 |

**剧本元素类型色**（场景元素流的标签/左边条颜色，帮助一眼区分）
| 元素 type | 颜色 | 视觉 |
|-----------|------|------|
| `action`（动作） | `#9DA7B3` 灰 | 中性 |
| `dialogue`（对白） | `#2DD4BF` 青 | 最醒目 |
| `voiceover`（V.O.画外音） | `#A78BFA` 紫 | |
| `transition`（转场） | `#E8B349` 琥珀 | |
| `montage`（蒙太奇） | `#F472B6` 粉 | |
| `parenthetical`（情绪提示） | `#6E7681` 弱灰 | 斜体 |

### 2.2 字体
| 用途 | 字体 | 说明 |
|------|------|------|
| UI 界面 | Inter / Noto Sans SC（思源黑体） | 中英混排 |
| 剧本预览 | Courier Prime / 等宽 | Fountain 行业惯例，打字机质感 |
| YAML/代码 | JetBrains Mono / Fira Code | 等宽，连字 |

**字号阶梯**：`H1 24 / H2 20 / H3 16 / Body 14 / Small 12 / Caption 11`，行高 1.5。

### 2.3 间距 / 圆角 / 阴影
- 间距阶梯（px）：`4 · 8 · 12 · 16 · 24 · 32 · 48`
- 圆角：控件 `6` ｜ 卡片 `10` ｜ 标签 pill `999`
- 阴影（深色用描边+微光替代重投影）：卡片 `0 1px 0 rgba(255,255,255,0.03) inset, 0 8px 24px rgba(0,0,0,0.4)`；强调发光 `0 0 0 3px accent/soft`
- 栅格：12 列，间距 24，最大内容宽 1440，三栏工作台自适应铺满。

### 2.4 图标
线性图标（Lucide 风格）：上传、播放、章节、人物、场景、对白、镜头、校验对勾、警告、下载、复制、眼睛(预览)、刷新(重校验)。

## 5. 组件清单（Component Library）

> 按原子设计组织，括号内为关键状态。

**基础**：Button（主/次/幽灵/危险/禁用/加载）、IconButton、Tag/Chip（元素类型色）、Badge（数字/状态）、Tooltip、Divider、Avatar（角色首字）、ProgressBar、ProgressRing、Toast、Modal、Drawer、Tabs、Dropdown/Select、SegmentedControl（视图切换）、Skeleton（加载骨架）。

**业务组件**：
- `UploadDropzone` —— 拖拽/点选 txt + 示例选择（空/拖拽中/已选/错误）。
- `ModelSelector` —— provider + base-url + model + key（脱敏显示）。
- `StageStepper` —— 四阶段进度（待处理/进行中/完成/失败）。
- `LiveLogFeed` —— SSE 流式日志条目（角色发现、场景生成…）。
- `SceneOutlineItem` —— 左栏场景行（编号·地点·时间·在场人数，选中/警告态）。
- `SceneCard` —— 场景卡（头部 slug + 元素流 + 标注层）。
- `ElementRow` —— 元素行（action/dialogue/…，左色条 + 可编辑文本，悬停显操作）。
- `DialogueBlock` —— 对白块（角色头像/名 + 情绪 parenthetical + 台词）。
- `ShotChip` / `MoodTag` / `PacingTag` —— 分镜/情绪/节奏标注。
- `CharacterCard` —— 角色卡（名 + 别名 chips + 角色 + 关系）。
- `YamlEditor` —— Monaco 容器（行号、校验下划线、错误悬浮）。
- `QualityGauge` —— 评分仪表 + 指标条组。
- `ScreenplayPage` —— Fountain 风格排版页。
- `SourceTracePopover` —— 原文片段溯源浮层。

```
│ ▎对白  ◍家珍 (冷冷)  你又去赌了。                      ✎ ⧉ 🗑     │
│ ▎对白  ◍福贵 (心虚)  就最后一次。                                  │
│ ▎画外音 ◍福贵        那是我最后悔的一夜。                          │
│ ＋ 添加元素:  [动作] [对白] [画外音] [转场] [蒙太奇]    ④          │
├──────────────────────────────────────────────────────────────────┤
```

**标注**
- ① slug 三段结构化下拉/输入（INT/EXT、地点、时间），缺失项黄色高亮。
- ② 在场角色引用 `characters` 注册表，支持增删。
- ③ `ElementRow` 行内操作：编辑 / 复制 / 删除 / 转换类型。
- ④ 添加元素按类型，颜色与类型色一致。
- ⑤ **P4b 标注层**：`ShotChip`/`MoodTag`/`PacingTag`，可选填、可一键 AI 建议。
- ⑥ `SourceTracePopover`：点开看对应原文片段，建立信任、支持局部重生成。


## 7. 关键交互与状态

| 场景 | 状态设计 |
|------|----------|
| 上传校验 | 拖拽中高亮边框；非 txt/不足 3 章 → 红字提示 |
| 生成中 | P2 阶段步进 + SSE 日志流 + 角色面板实时增长；可取消 |
| 失败/重试 | 阶段标红 + 错误信息 + [重试该阶段]；Compose 失败自动触发"修复中…"再校验 |
| 双向同步 | 卡片/YAML 任一编辑，对侧即时刷新；冲突时以最后编辑为准并提示 |
| 校验 | 合法 ✓绿徽标；不合法 ⚠ + 错误数；点徽标列出问题并可定位 |
| 空状态 | 工作台无场景 → 引导"返回上传"；右栏无角色 → 占位插画 |
| 加载 | 列表/卡片用 `Skeleton` 骨架屏 |
| 反馈 | 保存/复制/导出用 `Toast` 轻提示 |

## 8. 响应式与适配

- **设计基准**：1440 宽桌面（演示主场景），三栏铺满。
- **≤1200**：右栏（角色/质量）收为可切换抽屉，中栏变宽。
- **≤900**：左栏大纲收为顶部下拉；以中栏编辑为主（演示不主打移动端，能用即可）。
- 深色为默认主题；预留浅色主题切换位（令牌已抽象，便于换肤）。

## 9. 比赛演示动线（建议讲解顺序）

1. **P1** 点示例《活着》→ 强调"无 Key 也能跑"。
2. **P2** 让评委看 SSE：日志里"归并'老爷'→福贵""切出场景 S3" → 点题**跨章一致性**。
3. **P3** 三栏工作台：左大纲、中卡片、右角色圣经 + 质量分 87。
4. **P5** 改 YAML 一行 mood → 左侧卡片即时变 → 展示**双向同步**。
5. **P7** 质量报告 → 点 S4 警告"缺时间"定位 → 展示**可量化、可定位**。
6. **P8** 一键预览 Fountain 剧本 → "这就是作者认得的剧本"。
7. **P9** 导出 YAML/剧本 → 收尾。

## 10. 交付与标注说明（给 Open Design）

- 命名建议：页面用 `P{n}-{名}`，组件用 `Comp/{类}/{名}`，令牌用 `bg/`、`text/`、`accent/` 前缀。
- 把第 2 节令牌建为 Variables/Styles；第 5 节组件建为 Components 并做变体（Variant：状态）。
- 原型连线按第 6 节主动线 + 第 7 节状态切换。
- 交互重点做三处「会被现场演示」的：P2 进度流、P5 双向同步、P7 警告定位。
